# CO2分離膜分野 翻訳・単位換算辞書

- Permeance: 透過度（単位: `mol/m2skPa`）
- task-specific ionic liquid: タスク特化型イオン液体（TSIL）
- protic ionic liquid: プロトン性イオン液体
- aprotic ionic liquid: 非プロトン性イオン液体
- Polymers of Intrinsic Microporosity (PIM): 固有微細孔性高分子
- Mixed Matrix Membrane (MMM): 有機-無機ハイブリッド膜
- Metal Organic Frameworks (MOF): 金属有機構造体
- 1 GPU = 3.349e-7 mol/m2skPa
- 1 Barrer = 3.346e-13 molm/m2skPa

Ionic-liquid notation such as [TBP][SCN] and [EMPyrr][SCN] must be enclosed in Markdown backticks.
